The problem

Other Facebook scrapers quietly fail.

You've probably tried one of them. They run for a few hours, Facebook detects them, and everything stops. Here's why.

PROBLEM 01

Single account, single point of failure

One account hits a rate limit — the entire scraping job stops. You lose hours of work, and there's no way to recover except to wait and try again.

PROBLEM 02

Headless browsers get flagged fast

Facebook knows what a Puppeteer script looks like. Within an hour or two, headless browsers are blocked — and your account is flagged for good.

PROBLEM 03

Duplicate data ruins the output

"See more" splits posts into pieces. Most scrapers save each fragment separately. You end up with the same post 3–4 times, and cleaning it becomes your problem.

The solution

Three things this scraper does differently.

Every architectural decision was made to solve the three problems above. No shortcuts, no workarounds.

1

Real browser, not headless

It uses Microsoft's actual Edge engine (WebView2) — the same one your normal browser uses. Facebook can't tell the difference.

  • Same fingerprint as a real user
  • Login once — stays logged in for weeks
  • No detection by Facebook's bot filters
2

Multiple instances in parallel

Run as many copies as you have accounts and proxies for. Each one is completely independent — same tool, unlimited power.

  • Own account + proxy per instance
  • Own database + logs — full isolation
  • One rate-limited? The rest keep going
3

Clean, deduplicated data

FTS5 full-text index + SHA-256 hashing + bidirectional containment check. The "See more" problem is solved at the database level.

  • Zero duplicates — ever
  • Full post text, not fragments
  • Indexed and searchable instantly

Under the hood

Everything you'd expect. Plus the things you wouldn't.

Real WebView2 engine

Uses the same Chromium engine as Microsoft Edge. Facebook sees a normal browser, not a bot.

Full SOCKS4/5 support

HTTP, HTTPS, SOCKS4, and SOCKS5 with username/password auth. Applied to browser and downloads.

Parallel video downloads

Videos fetched with concurrent Range requests. -videoconcurrency=1..16 to tune.

FTS5 deduplication

SQLite full-text index + SHA-256 hashing. Duplicates are impossible by construction.

Named-pipe DB writer

Writes go through a separate process. Scraper never blocks on I/O. Local SQLite fallback built in.

Structured JSON logging

Rotated by size, level-filtered, credentials sanitized. Ready for log aggregation tools.

Auto-recovery with limits

Crashes trigger restart, but a sliding-window counter prevents infinite restart loops.

Live control via pipe

Pause, resume, reload, add profiles, change proxy — all without restarting the app.

Yours stays yours

Never steals mouse or keyboard focus. Runs minimised or fully hidden while you work.

Common questions

Things people ask before buying.

Does it work on Mac or Linux?
No. This is a Windows application, built around Microsoft's WebView2 browser engine. It requires Windows 10 or 11 (64-bit). For Mac or Linux, you'd need the managed service — we run it on our servers and deliver the data to you.

How many instances can I run at once?
As many as your hardware can handle. There's no artificial limit. Each instance uses roughly 300–500 MB of RAM and is a normal Windows process. Most customers comfortably run 5–10 instances on a standard machine. The license covers unlimited instances on one machine.

Do I need to provide my own proxies?
Yes for the self-hosted version. You provide the proxies and assign one to each instance. The app supports HTTP, HTTPS, SOCKS4, and SOCKS5 with authentication. For the managed service, we handle all proxy infrastructure for you.

Will my Facebook account get banned?
Because the scraper uses a real WebView2 browser (not headless automation), Facebook sees normal user activity. Combined with proper proxies and reasonable delays, accounts stay safe in long-term use. That said, no scraper can guarantee 100% account safety — you should always use accounts you're comfortable risking for data collection purposes.
