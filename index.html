web api

Full control through simple HTTP requests.

For teams that want to schedule jobs, connect the tool to internal dashboards, or trigger scraping from another application — everything the desktop app can do is also available through the API.

Everything programmable.

Start jobs, check progress, download results, change settings — all through standard HTTP calls. Works with any programming language, any automation tool, any scheduling platform.

POST
/api/jobs/start
Launch a new scraping job with your parameters.
GET
/api/jobs/{id}/status
Check progress, counts, and ETA in real time.
POST
/api/jobs/{id}/pause
Pause a running job. Resume any time.
POST
/api/jobs/{id}/stop
Stop the job and finalize the dataset.
GET
/api/jobs/{id}/download
Download the current dataset in JSON, CSV, or SQLite.
POST
/api/jobs/{id}/config
Change targets, proxies, speed, or filters on the fly.
GET
/api/jobs/{id}/logs
Stream structured logs for monitoring and alerting.
DEL
/api/jobs/{id}
Delete a job and its associated data.
# Start a new job
curl -X POST https://panel.your-job.com/api/jobs/start \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "profiles": ["brandpage", "competitor1"],
    "start_date": "2025-01-01",

under the hood

Why it works when other tools don't.

The technical reasons this handles jobs that break most scrapers.

🔒

Looks like a real browser

Facebook blocks tools that pretend to be browsers. This one uses the same engine Microsoft Edge uses — Facebook can't tell the difference. You log in once, and it stays logged in.

👥

Run several jobs at once

Five clients? Run five copies simultaneously, each with its own Facebook account and proxy. If one gets blocked, the others keep working.

🎬

Fast video downloads

Videos are downloaded in parallel instead of one at a time. A 100-video page finishes in minutes, not hours.

🧹

No duplicate mess

Facebook splits posts into pieces. Most tools save the same post 3 times. This one recognizes duplicates and stores only the full version.

🖥️

Live web dashboard

A built-in website opens in your browser. See new posts as they arrive, view the media, change settings — all without touching the desktop app.

🌐

Works with any proxy

If you have a proxy server, it uses it. If you don't, it doesn't need one. Supports all common types including SOCKS5.

📮

Push to your tools

Every post can be sent automatically to your CRM, database, or spreadsheet — the moment it's collected. No manual export.

🔌

Full REST API

Start jobs, check progress, download data, change settings — all programmable. Perfect for scheduled runs and integrations.

⌨️

Your PC stays yours

Does not steal your mouse, does not steal your keyboard, does not pop up windows while you type. Runs silently in the background.

technical details

What you're actually running.

Concrete answers for the people who have to install this on a real machine.

Operating system
Windows 10 or Windows 11 (64-bit)
Browser engine
Microsoft Edge WebView2 (real browser, not a fake one)
Where data is stored
SQLite database file · optional separate writer process
Video processing
Requires ffmpeg in PATH · automatic audio-video merging
Proxy support
HTTP · HTTPS · SOCKS4 · SOCKS5 with authentication
Control panel
Desktop window + built-in web page on localhost · also reachable from other devices on your network
Web API
Full REST endpoints for jobs, status, download, config, logs, control
Background mode
Runs minimised or hidden · never takes over your mouse or keyboard
Authentication
Bearer tokens for API · password + session cookies for the web panel
Settings
Simple text file (scrapsettings.json) + command-line options
Isolation
Each copy has its own login, database, log file, and port
Logs
Rotated automatically · proxy passwords hidden from log files
License
Per installation · source code available for enterprise buyers

// what this does NOT do

  • It does not run on Mac, Linux, or inside Docker. It's a Windows program (or our hosted service).
  • It does not log in to Facebook for you. You provide the account and log in once.
  • It does not rotate proxies automatically. You provide the proxy — or run multiple copies.
  • It is not a hack, a crack, or a way to bypass Facebook's rules. Use it responsibly.
  • It is not a "growth hacking" tool. It collects public data — it doesn't post, like, or comment.
